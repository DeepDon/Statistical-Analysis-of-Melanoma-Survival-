This report conducts an exploratory data analysis of a dataset focused on malignant melanoma 
survivors. The dataset comprises records of individuals who had surgery to treat malignant 
melanoma at Odense University Hospital in Denmark during the period from 1962 to 1977. The 
statistical computations and data visualizations were carried out using RStudio. Key variables 
identified in the dataset include ulceration, tumour thickness, and survival time, which were 
found to significantly influence mortality rates, with thicker tumours and ulcer presence being 
associated with higher mortality.
